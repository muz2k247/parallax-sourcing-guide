# Parallax 2026: Gift & Vendor Sourcing Guide

An executive procurement guide and interactive budget modeling tool built for the **CSS Society** event management committee for the **Parallax 2026** signature event.

## Features

- **Interactive Financial Modeling & Budget Calculator**: Direct unit rate editing, quantity adjustments, custom expense item creation, and live budget allocation visualization across recipient tiers (Chief Guest, Contributors & Vendors, VIP Gifts, and Custom items).
- **Vetted Pakistani Suppliers Directory**: 10 verified commercial vendors with catalog offerings, active URLs, price benchmarks, logistics SLAs, Minimum Order Quantities (MOQ), and operational caveats.
- **Recipient Gifting Protocol**: Structured 3-tier gifting framework tailored for dignitaries, institutional partners, and delegates.
- **Ordering & Verification Checklist**: Quality control protocol covering artwork proofing, vendor WhatsApp verification for high-spend line items, and delivery buffers.
- **Verified Executive Summary Modal**: Formatted plain-text and structured summary ready for one-click clipboard copying and executive circulation.
- **Executive Dark/Light Themes**: Refined high-contrast typographic hierarchy using Plus Jakarta Sans, Newsreader serif, and JetBrains Mono tabular numerals.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone <your-repo-url>
cd <repo-folder>

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application runs locally on `http://localhost:3000`.

### Production Build

```bash
npm run build
```
